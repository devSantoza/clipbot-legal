Effective date: November 20, 2026

This policy describes the intended handling of information when using ClipBot 4.0, a desktop tool for creating, organizing, scheduling and analyzing video clips. The application is maintained by the developer of devSantoza.

Developer review: This policy must be checked against the actual application behavior before it is used for a TikTok production review. In particular, confirm token storage, diagnostics, deletion and third-party service behavior.

Information used

Depending on features you enable, ClipBot may process local video files and clip metadata; account identifiers and public video information; publication IDs, URLs and status; performance metrics such as views, likes, comments and shares; and OAuth authorization tokens needed to access connected services.

Why information is used

Information is used to create and organize clips, connect accounts you authorize, synchronize publication history, prevent duplicate uploads, schedule content, and display performance reports.

Connected services

Optional integrations may involve TikTok, YouTube/Google and an AI analysis provider (Gemini). These services process data according to their own terms and privacy policies. Only connect accounts and provide content that you are authorized to use. ClipBot should request only permissions needed for enabled features.

Storage and security

ClipBot is designed to maintain local project data and caches on the user's computer. Its TikTok integration is intended to store authorization credentials using Windows-protected storage. The developer should verify this implementation and identify any data transmitted to external services before submitting the app for review. No storage or transmission system can be guaranteed completely secure.

Retention and deletion

Local data may remain until the user removes it or uninstalls the application. Removing a connected account's access does not necessarily erase existing local records. To request help identifying and deleting stored data, contact the developer using the repository link below. Do not assume that deleting a locally exported clip removes content already published to a platform.

Choices and revocation

You may choose whether to connect supported accounts. You can revoke a service's authorization through that service's account settings. Revoking access may disable synchronization, publishing and analytics.

Contact and changes

For privacy questions, use the project's GitHub issues. Do not post passwords, tokens or private personal information in public issues. This policy may be updated as features or integrations change.
